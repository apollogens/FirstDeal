# Архитектура frontend

Учебный проект, созданный в рамках хакатона. Здесь описана клиентская часть существующего приложения; backend и внешние AI-сервисы подключаются отдельно.

## Структура и ответственность

`src/app` содержит Next.js App Router, layout и route handlers. `SessionWorkspace` загружает сессию, `AppShell` координирует навигацию и выбранный экран. `src/components` содержит экраны и общие элементы; `src/features` — историю, календарь и документы с адаптерами представления. `src/lib` отделяет API-клиенты, доменные типы, runtime guards и presentation helpers.

Состояние интерфейса управляется React hooks. Local storage хранит пользовательские предпочтения и локальные overlays; он не заменяет backend и не является источником прав доступа.

## Типизация и API

Схема запроса: браузер → Next route handler → существующий API. Работа с backend-сессией остаётся в серверных helpers; доменные клиенты проверяют ответы перед передачей в компоненты.

Внешний JSON имеет тип `unknown`. Guards проверяют обязательные, optional и nullable поля, массивы, даты, валюты и decimal-значения. WebSocket envelopes и payload проверяются отдельно. Действия чата описаны discriminated union; интерфейс показывает подтверждение до выполнения действия.

Включены strict TypeScript и type-aware ESLint. В собственном `src` отсутствует explicit `any`; это требование не распространяется на внутренние типы сторонних библиотек. Типы не подменяют runtime-валидацию и серверную авторизацию.

## Стили и взаимодействие

CSS Modules изолируют стили, `src/app/globals.css` хранит общие токены и импорты шрифтов. Используются Grid, Flexbox, ограничение длинного контента и собственная прокрутка широких элементов. Пример БЭМ — `history-chat-row`, его элементы и модификаторы; массовая миграция остальных классов не выполнялась.

ThemeController поддерживает light/dark/system, отслеживает OS и изменения другой вкладки. Dialog hooks управляют фокусом, верхним вложенным окном, Escape и блокировкой фона. Popover hooks рассчитывают положение с учётом viewport.

Мобильная версия находится в разработке. На телефоне доступны выдвигаемая навигация, дневной календарь, вертикальные статусы задач и компактные панели. На desktop сохраняются многоколоночные представления.

## Безопасное отображение

Пользовательский текст и содержимое чата отображаются через React-элементы; произвольный HTML не исполняется. Markdown-ссылки ограничены HTTP(S). Уведомления об ошибках, loading/empty состояния и подтверждения действий являются частью интерфейса. Эти меры не заменяют серверные проверки.

## Конфигурация

Имена переменных — в `frontend/.env.example`:

- `AUTH_API_URL`: origin backend, используемый сервером Next.
- `AUTH_APP_ORIGIN` / `AUTH_APP_ORIGINS`: разрешённые origins frontend.
- `NEXT_PUBLIC_WS_API_URL`: доступный браузеру адрес WebSocket без credentials.

Реальные значения хранятся в игнорируемом `.env.local`. Для локального просмотра без backend предусмотрен read-only fixture-сервер `npm run demo:portfolio`. Его нельзя подключать к настоящим учётным данным или публиковать как работающую production-интеграцию.
