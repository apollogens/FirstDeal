# Происхождение и границы frontend-работы

Учебный командный проект, созданный в рамках хакатона. Репозиторий представляет frontend-разработку существующего приложения: вёрстку, компоненты, интеграцию с API, типизацию, темы, адаптацию и проверки интерфейса.

Серверная часть и AI-возможности не заявляются как личная frontend-разработка. Публикация frontend не меняет авторство исходного командного проекта. Название мероприятия, организаторы и детали участия здесь не раскрываются.

Мобильная версия находится в разработке. Скриншоты используют демонстрационные данные; полноценная работа реальных внешних сервисов ими не подтверждается. Физическая экранная клавиатура, screen reader, WebKit/Firefox и полная WCAG-сертификация не проверены в текущей приёмке.

Новая лицензия на командный код и иллюстрации не назначается. Исходные авторские права и условия сторонних пакетов, шрифтов и ресурсов сохраняются. Это учебный исходный код; наличие публичного репозитория само по себе не предоставляет отдельного разрешения на повторное использование всех материалов.

История исходного репозитория, серверные конфигурации, credentials, пользовательские данные и локальные QA-артефакты в frontend-публикацию не переносятся. Для реального deployment необходимо отдельно настроить backend, секреты, внешние сервисы и выполнить эксплуатационную проверку.
