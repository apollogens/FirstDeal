# Workspace AI · Frontend

Учебный frontend-проект на Next.js, React, TypeScript и CSS Modules. Мобильная версия находится в разработке.

Основной README со скриншотами и описанием вёрстки, API, строгой типизации и применения БЭМ: [Workspace AI](../README.md).

```sh
npm ci --ignore-scripts
npm run demo:portfolio
```

Локальный просмотр: http://127.0.0.1:3210/login. Используйте вымышленные данные; настоящие credentials и backend для fixture-просмотра не требуются. Для настоящего API настройте `.env.local` по `.env.example` и запустите `npm run dev`.
